# Search Toolkit × Media Bias PRISM v3.1

Google Cleaner、AI Search Assistant（ページ内検索・検索転送）、Media Bias PRISMを統合したManifest V3拡張です。

## 統合元
- `Nozian/Google-Cleaner` — Google検索結果の広告/AI/関連質問の表示整理と6種の検索Tips
- `Nozian/AI-Search-Assistant` — Google / Bing / DuckDuckGo / AIへの横断検索、右クリック、検索結果内の比較ボタン、検索転送補助
- `Nozian/remake-media-bias-detector`（`mbd 5/`）— PRISMの4つの分析アクション（要約／バイアス分析／ファクトチェック／深掘り検索）、ニュース/X/Google検索対応を移植・統合

**旧「元のAI検索」ポップアップは削除**。統合検索の機能と、検索結果/AIサイトの横断検索ボタンは維持しています。PRISMポップアップは新設しました。PRISMのコードは旧機能を元に再実装しており、ファイルを単純に結合したものではありません。

## 機能
1. ポップアップの「横断検索」で検索先を複数選び、一括でタブを開く
2. 「メディアバイアス PRISM」で今のニュース記事を要約／偏り分析／ファクトチェック／背景検索に渡す
3. Googleニュース、Yahooニュース、X、Google検索の記事カードでPRISMの4ボタンを利用（対応サイトはmanifestに記載）
4. 主要ニュースサイトで画面左下にPRISM分析ボタンを表示
5. Google Cleanerの歯車パネル・検索演算子・元のページ内横断検索機能は残す

## プライバシー・留意点
- PRISMは利用者が「ファクトチェック」などを押した際、選んだAIサービスの入力欄に分析文の**自動挿入を試みます**。送信は行いません。失敗した場合はAIページ内に「再入力」「コピー」を表示します。背景検索はユーザー操作時のみ開きます。
- 一次資料を含めた検証をAIに依頼するための補助機能で、真偽を自動保証しません。
- サイトのDOM仕様変更でボタンが表示されない可能性があります。
- 拡張を別IDとして追加した場合、旧拡張の履歴・設定が自動移行されるとは限りません。旧拡張をすぐに削除しないでください。

## インストール
1. ZIPを展開する。
2. Chrome `chrome://extensions/` → デベロッパーモード → パッケージ化されていない拡張機能を読み込む。
3. `Search-Toolkit` フォルダーを選択する。
4. 旧版を無効化し、対象タブを再読み込みする。

## テスト範囲
JavaScript構文、Manifest/参照ファイル、模擬Google検索結果のPRISM4ボタン、模擬ポップアップのタブ切替を確認。実際のGoogle/Netflix等のサービスへのログインを伴うブラウザ検証は未実施です。

## v3.1 — PRISM自動入力（2026-10-24）
- 「ファクトチェック」「要約」「バイアス分析」をクリックすると、ChatGPT / Perplexity / Grok / Gemini / Claudeを新しいタブで開き、分析文をその入力欄に自動でセットするよう試みます。**送信はしません**。
- AIサービスによって入力欄の構造が変わるため、ログイン画面や変更後は失敗することがあります。その場合は画面内の「再入力」「コピー」から復旧できます。
- 保留中の入力文は `chrome.storage.session` に一時保存し、入力処理後に削除します。サービス側へのアクセスと入力はユーザーの分析操作のときだけ行います。
- Google Cleanerの歯車、検索演算子、ページ内検索比較ボタン、検索履歴、横断検索の機能を維持します。
- テスト：模擬AI入力欄へ文章が入り、送信ボタンは動かないことを確認済み。**実サイトの各AIでは未検証**です。

## v3.1.1 — X/Twitterの表示修正（2026-10-30）
- 投稿の下部に重なっていたPRISMツールバーを廃止し、標準の返信・リポスト・いいね等の操作列の下に小さな「PRISM ▾」ボタンを置くよう変更。クリック時だけ4つの分析機能を展開します。
- Xの標準操作列に挿入していた旧Google検索ボタンをXのみ無効化。Googleでの調査はPRISMの「深掘り検索」に残しています。
- X上の分析メニューはクリックで開き、投稿の操作列を覆わないよう通常のレイアウト内に表示。ほかのサイトの既存ホバー表示は維持しています。
- 投稿の要素がXの動的更新で再利用されても、PRISMが古いリンクを保持しにくいよう挿入済みチェックを改善しました。
- 実際のログイン済みXでの目視・クリック検証は未実施です。

## v3.1.2 — PRISMのホバー説明（2026-10-30）
- 「要約」「バイアス分析」「ファクトチェック」「深掘り検索」に短い日本語の説明を追加しました。ボタンにマウスを乗せるとブラウザ標準のツールチップに表示されます。
- PRISMの開閉ボタン、分析先AI、Google / Perplexityの検索ボタンにも操作説明を追加。分析先への自動送信は行いません。
- Xの操作列を邪魔しないv3.1.1の折りたたみ表示、ほかの対応サイトの表示動作は維持しています。
- 実際のX上でのホバー表示と各AIの入力動作は未検証です。
